# Art direction: thor tveito

Calm, editorial, gallery-like. Swiss/International type meets a quiet photo-book.
Confident restraint: lots of negative space, hairlines instead of boxes, and the
photos are always the loudest thing on the page.

## Files

| File | What it holds |
| --- | --- |
| `style.css` | **All tokens**, base styles, logo, nav, header, footer, home page, text pages, entries, forms. Every page links it. |
| `gallery.css` | Photo room only (`bilder.html`). Uses tokens; adds no new colors. |
| `skriv.css`, `skriv.js` | The hidden writing page (`skriv.html`). Not in the nav. |
| `site.js` | The single source for the header, the nav and the footer. |
| `gallery.js`, `photos.json`, `beretninger.json` | The data contract: scripts and the writing page write the JSON, and the pages read it. |

## Adding a page

1. Add **one line** to `PAGES` in `site.js`: `{ href: 'om.html', label: 'Om' }`.
2. Copy `beretninger.html` as a starting point: keep the `<head>`, `<header data-site-header>`,
   `<main id="innhold">`, `<footer data-site-footer>` and `<script src="site.js">`.
3. Use `.grid` + `.page-head` for the title and `.prose` for text. Don't write new colors or sizes. Use the tokens.

The current page gets `aria-current="page"` automatically.

## Logo: the viewfinder

`thor tveito` in lowercase Instrument Serif italic, inside four camera crop marks, with
one accent focus dot in the top-right corner. Pure CSS (`.vf`): the corners are
`currentColor` background gradients, so the logo follows the text color in both themes
and scales with `font-size`.

```html
<span class="vf"><span class="vf-text">Thor Tveito</span></span>   <!-- base -->
class="vf vf--sm"    header (generated by site.js)
class="vf vf--hero"  home page, with the one load animation
```

- Write the name as `Thor Tveito` in the HTML. CSS lowercases it, and screen readers get proper case.
- Never recolor the corners. Never move the dot out of the top-right corner or add a second dot.
- Never put the logo on a box, a fill or a photo.
- Favicon: the same corners plus the dot, inlined as a data-URI SVG in each `<head>`.

## Color

| Token | Light | Dark | Use |
| --- | --- | --- | --- |
| `--bg` | `#f2efe9` paper | `#0d0d0d` ink | Page background |
| `--fg` | `#0d0d0d` | `#f2efe9` | Text, logo, active nav (16.9:1) |
| `--muted` | `#6a665f` (4.97:1) | `#9a958c` (6.53:1) | Labels, metadata, inactive nav |
| `--line` | `#d9d3c8` | `#2e2c29` | 1px hairlines, photo placeholders. Decoration only, never text. |
| `--accent` | `#a84a26` (4.98:1) | `#e0805a` (6.85:1) | Ember. See the rules below. |

Theme follows `prefers-color-scheme`. Every color comes from a token; the only literal
hex values are the token definitions, `theme-color` metas and the favicon.

**The accent is a seasoning, not a color scheme.** It is allowed in exactly these places:
the logo's focus dot, the current-page dot in the nav, `::selection`, `:focus-visible`
outlines, and link hover on `.text-link`. Not on headings, backgrounds, borders,
buttons or icons. If a page needs a second "highlight", it doesn't.

## Type

- **Display**: Instrument Serif (`--font-display`), 400 regular and italic. Used for the logo, `h1`–`h3`
  and photo captions. Never bold; hierarchy comes from size.
- **Body/UI**: Inter (`--font-body`), 400 and 500 only.
- Fallback stacks are in the tokens; the fonts load from Google Fonts with `display=swap`.

Fluid scale (`clamp()`): `--step--1` labels · `--step-0` body · `--step-1` small logo,
captions · `--step-2` · `--step-3` post titles · `--step-4` page titles ·
`--step-hero` home logo.

- Body text: `--leading-body` 1.7. Headings: `--leading-tight` 1.05, `text-wrap: balance`.
- **Labels** (`.label`): `--step--1`, Inter 500, uppercase, `--tracking-label` 0.14em, `--muted`.
  Use them for nav, dates, counts, hints and the footer. Keep them short.
- Reading width is at most `--measure` (60ch). Text is always left-aligned. The only
  centered things are the home composition (desktop) and the photo caption.

## Layout

- `.grid`: 4 columns on mobile and 12 from 48rem, gutter `--gutter`, side margin `--margin`
  (`clamp(1rem, 4.5vw, 4.5rem)`).
- Text pages: labels and metadata in columns 1–3, content from column 4 (`.page-head`,
  `.post`, `.prose`). On mobile everything stacks, with the label above.
- Spacing comes from `--space-1` … `--space-9` (4px base). Generous vertical rhythm:
  sections are separated by `--space-7`/`--space-8`, not by boxes.
- Header: small logo top-left, nav top-right, height `--header-h`. Footer: a hairline,
  then two labels.
- Separation is a 1px `--hairline`. **No cards, no shadows, no rounded corners, no fills.**

## Interaction and motion

- Nav links: muted → ink on hover, with a 1px line drawn from the left (`--dur`).
  The current page is ink with a 4px accent dot beneath it. No boxes and no buttons for navigation.
- Real controls (zoom, viewer) are `.icon-btn`: 44×44, square, hairline border,
  transparent. The border darkens on hover.
- Focus: `1.5px` accent outline, `4px` offset, on everything (`:focus-visible`).
- Touch targets are at least 44px tall.
- Motion tokens: `--dur-fast` 160ms, `--dur` 280ms, `--dur-reveal` 600ms, `--ease`.
- **One motion per page, at most.** The home logo reveals left-to-right once (600ms),
  and the focus dot appears after it. Nothing loops, parallaxes or bounces in the chrome
  (the photo room's camera is content, not chrome).
- `prefers-reduced-motion: reduce` zeroes all durations.

## Entries (Beretninger)

- Each entry is a `<details class="entry">`. Closed, it shows only the **date label, the title**
  and (on desktop) a photo count. A thin plus turns into a minus when it opens.
- Opened, the text sits in columns 4–10 and the photos get more room, in columns 4–12. The first photo
  is large and the rest come two by two. Portrait photos stop at 85% of the screen height.
- An open entry gets its own link (`beretninger.html#<id>`), so it can be shared.
- The open/close animation is a block-size transition on `::details-content`. Browsers without
  support just open instantly.
- Content in `<details>` doesn't inherit the page grid (`subgrid`), so `.entry-head` and
  `.entry-body` each declare the same 12 columns themselves.

## Forms

- `.input` / `.textarea`: no box, just a 1px `--line` underline that turns `--accent` on focus.
  `.input--title` uses the display serif.
- `.btn`: a 44px hairline frame in ink with uppercase label text. It fills with ink on hover. `.btn--quiet` uses
  a `--line` border and muted text. One solid-framed button per form (the main action).
- Field labels are muted; hints use `.hint-text` (`--step--1`, muted).

## Photos

- Photos are the hero; chrome recedes. Over photos, text gets a soft paper-colored
  `text-shadow` halo instead of a background plate.
- Captions are Instrument Serif italic, lowercase as written, and quiet.
- No borders, frames, shadows or rounded corners on images. Placeholders use `--line`.

## Do / don't

| Do | Don't |
| --- | --- |
| Leave space empty | Fill space because it's there |
| Use one hairline to separate | Use cards, panels or drop shadows |
| Use the accent in the 5 allowed spots | Make headings, buttons or icons ember |
| Set labels small, uppercase and tracked | Set body text in uppercase |
| Build hierarchy from size and the serif/sans contrast | Use bold weights (Inter stops at 500) |
| Add a page with one line in `site.js` | Hand-copy nav markup into a page |
| Write Norwegian (nb) | Mix in English UI copy |
| Check contrast for any new token pair (≥ 4.5:1 for text) | Use `--line` for text |
